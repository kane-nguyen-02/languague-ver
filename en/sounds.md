# EN — SOUND MAP (giáo trình chính của L0 EN, W1–3, ôn đến W12)

**Ưu tiên:** **P0** phải nghe ra và nói được · **P1** phải nghe ra · **P2** nên biết · **P3** nâng cao (hoãn).
**Test:** Nhận = nghe ra · Phân = phân biệt cặp · Nói = phát âm đúng · Dùng = dùng trong câu nói tự nhiên.
Thứ tự: **nghe ra trước, nói sau**. Gate L0 EN chỉ chấm P0 + P1 (xem `GATES.md`).

## E. Connected speech
### 1. Linking
| Loại | Ví dụ | Ưu tiên |
|---|---|---|
| Phụ âm → nguyên âm | turn it off → *tur-ni-doff*, pick it up | P0 |
| Nguyên âm → nguyên âm (chèn /j/) | I am → *I-yam*, see it → *see-yit* | P1 |
| Nguyên âm → nguyên âm (chèn /w/) | go out → *go-wout*, do it → *do-wit* | P1 |
| Nối /r/ | far away, where is | P1 |
| /r/ chêm (giọng Anh) | idea of → *idea-r-of* | P3 |

### 2. Flap T (Mỹ) — P0 nghe ra, P1 nói
water, better, city, pretty, get it → *ge-dit*, what are → *whad-er*, a lot of → *a-la-də*.
Test: nghe nhận ra, phân biệt *latter/ladder*, nói 5 câu.

### 3. Elision (nuốt âm)
| Loại | Ví dụ | Ưu tiên |
|---|---|---|
| Bỏ /t/ | next day, last night, must be | P0 |
| Bỏ /d/ | and then → *an then*, old man | P1 |
| Bỏ /h/ ở từ chức năng | tell him → *tell-im*, ask her → *ask-er* | P0 |
| Bỏ schwa | probably → *prob-ly*, camera → *cam-ra*, family → *fam-ly* | P1 |
| Rút gọn cụm phụ âm | asked → *ast*, months → *mons* | P1 |
| Phụ âm cuối yếu/nuốt (chặn tắc) | that guy → *tha' guy* | P1 |

### 5. Rút gọn — 18 dạng (Nhận = P0; dùng khi nói tùy mức trang trọng)
Mức dùng: **T** trang trọng = không dùng · **N** nói chuyện thường = dùng được · **C** thân mật = chỉ với bạn bè.
| Đầy đủ | Rút gọn | Dùng khi nói |
|---|---|---|
| want to | wanna | N |
| going to | gonna | N |
| got to | gotta | N |
| have to | hafta | N |
| used to | useta | N |
| supposed to | s'posed to | N |
| kind of | kinda | N |
| sort of | sorta | N |
| a lot of | a lotta | N |
| give me | gimme | C |
| let me | lemme | N |
| tell him | tell'im | N |
| don't know | dunno | C |
| did you | didja | N |
| could you | couldja | N |
| would you | wouldja | N |
| what do you | whaddaya | C |
| what are you | whaddaya / whatcha | C |

Quy tắc: **nghe ra 100% cả 18 dạng** (P0). **Khi nói:** chỉ dùng mức N; mức C chỉ dùng với bạn bè. Viết email và họp trang trọng không dùng.

### 6. Đồng hóa âm
| Loại | Ví dụ | Ưu tiên |
|---|---|---|
| Hợp âm (t/d + you) | did you → *didja*, don't you → *doncha*, meet you → *meechu*, would you → *wouldja* | P0 nghe ra |
| Đổi vị trí | ten people → *tem people*, good boy → *goob boy* | P2 |
| Đổi hữu thanh/vô thanh | have to → *hafta*, used to → *useta* | P1 |
| Đổi cách phát âm | in the → *in-ne* | P3 |

### 7. Hiện tượng khác
| Mục | Ưu tiên |
|---|---|
| Schwa /ə/: nguyên âm hay gặp nhất, có mặt trong mọi từ không nhấn | P0 |
| Ngữ điệu: câu hỏi Yes/No lên giọng, câu hỏi Wh- xuống giọng, giọng ngạc nhiên lên cao | P0 |
| Nén cụm (the end of the → *thee-en-də-thə*) | P1 |

| Bật tắc thanh hầu (button → *bu'n*, Mỹ) | P2 nghe ra |
| Giảm trọng âm từ trong câu nhanh | P2 |

## Bộ test L0 EN (agent sinh đề MỚI mỗi lần)
1. **Phân biệt cặp âm** 20 câu (mục A, P0) → ≥85%
2. **Chép chính tả** 10 câu tốc độ thật có weak form/rút gọn → viết đầy đủ → ≥85% từ đúng
3. **Tách từ**: nghe *"whaddaya wanna do"* → tách thành từ → 10 câu → ≥85%
4. **Nhận trọng âm**: nghe → đánh dấu từ được nhấn → 10 câu → ≥80%
5. **Nói**: shadow 10 câu, chấm phụ âm cuối + -s/-ed + nhịp → ≥80%
