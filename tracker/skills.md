# SKILLS — trạng thái từng kỹ năng + lịch ôn giãn cách

- Trạng thái: **K** biết → **R** nhận ra khi nghe → **U** dùng được có gợi ý → **A** tự động (≤3s, trong hội thoại).
- Kỹ năng vừa PASS: đặt lịch ôn sau **1 → 3 → 7 → 14 ngày**. Cứ ôn đạt thì chuyển sang mốc tiếp theo. Lần ôn nào dưới ngưỡng → **REVIEW**, ôn lại từ mốc 1 ngày.
- `ÔN HẠN`: agent lọc các dòng có "Ôn kế tiếp" ≤ hôm nay và test bằng đề mới.
